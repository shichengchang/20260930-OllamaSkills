# 範例說明 - FENTAY B2B 訂單匯入

> 注意：EXAMPLES 僅供格式參考。實際處理時，**輸入有多少筆就輸出多少筆**，不得截斷！

---

## 範例 1: 豐泰 PDF 訂單匯入（單筆）

### 輸入: PDF 表格資料（豐泰訂購單）

| 訂購單號 | 料號 | 材料名稱/顏色代碼 | 規格 | 數量 | 單位 | 單價 | 金額 | 交貨日期 | 需求子公司 |
|---------|------|----------------|------|------|------|------|------|---------|---------|
| 6AF1101 | 3056G | 44"74F黃LJ-A8-P網布/(74F) | 44" | 820.0 | 碼 | 73.00 | 59,860.00 | 2026/03/27 | LU1 |

### 欄位對照說明

| PDF 欄位 | 原始值 | 處理方式 | 輸出欄位 | 輸出值 |
|---------|--------|---------|---------|--------|
| 訂購單號 | 6AF1101 | 直接填入 | ORD_NO | "6AF1101" |
| 料號 | 3056G | 直接填入 | MATM_NAME | "3056G" |
| 材料名稱/顏色代碼 | 44"74F黃LJ-A8-P網布/(74F) | 直接填入 | MATM_DESC | "44\"74F黃LJ-A8-P網布/(74F)" |
| 規格 | 44" | 去除雙引號 | WIDE | "44" |
| 數量 | 820.0 | 保留小數 2 位 | QTY | 820.0 |
| 單位 | 碼 | 碼 → YD | UNIT | "YD" |
| 單價 | 73.00 | 保留小數 3 位 | PRICE | 73.000 |
| 金額 | 59,860.00 | 略過不匯入 | （無） | （略） |
| 交貨日期 | 2026/03/27 | 去除斜線 | NEED_DATE | "20260327" |
| 需求子公司 | LU1 | 直接填入 | NEED_CUST | "LU1" |

### 處理後 JSON 輸出

{
  "success": true,
  "recordCount": 1,
  "data": [
    {
      "ORD_NO": "6AF1101",
      "MATM_NAME": "3056G",
      "MATM_DESC": "44\"74F黃LJ-A8-P網布/(74F)",
      "WIDE": "44",
      "QTY": 820.0,
      "UNIT": "YD",
      "PRICE": 73.000,
      "NEED_DATE": "20260327",
      "NEED_CUST": "LU1",
      "BRAND_NO": "",

    }

## 範例 3: 缺漏欄位處理

### 輸入: 部分欄位缺漏的資料列

| 訂購單號 | 料號 | 材料名稱/顏色代碼 | 規格 | 數量 | 單位 | 單價 | 金額 | 交貨日期 | 需求子公司 |

| 6AF1200 | | 56"P28黑特利 | 56" | 547.0 | 碼 | 7.80 | | | LU1 |

### 處理後 JSON 輸出

```json
{

  "recordCount": 1,
  "data": [
    {
      "ORD_NO": "6AF1200",
      "MATM_NAME": "",

```

### 缺漏欄位處理規則說明

| 欄位類型 | 缺漏時填入 |
|---------|-----------|
| 字串欄位（VARCHAR2） | 空字串 `""` |
| 數值欄位（NUMBER） | `null` |
| 日期字串欄位（NEED_DATE） | 空字串 `""` |

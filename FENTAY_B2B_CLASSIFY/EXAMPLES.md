# 範例說明 - FENTAY B2B CLASSIFY

> 注意：範例的欄位順序、欄位數、資料值皆刻意與實際訂單不同，僅供輸出格式參考。
> 實際判斷以輸入的樣本內容為準，不可直接沿用範例的 mapping。

---

## 範例 1: 無表頭，含無對應欄位（備註）

### 輸入

欄位數 N = 11

```
R0: 0=6AF3101 | 1=7801K | 2=44"3AB灰網布/(3AB) | 3=44" | 4=碼 | 5=500.0 | 6=22.00 | 7=11,000.00 | 8=2026/06/12 | 9=急單 | 10=LU1
R1: 0=6AF3102 | 1=7802K | 2=60"3AC黃網布/(3AC) | 3=60" | 4=碼 | 5=1,200.0 | 6=18.50 | 7=22,200.00 | 8=2026/06/19 | 9= | 10=DS1
R2: 0=6AF3103 | 1=7803K | 2=44"3AD黑保利布/(3AD) | 3=44" | 4=公尺 | 5=36.0 | 6=95.00 | 7=3,420.00 | 8=2026/06/19 | 9= | 10=LU1
```

### 判斷說明

| 欄位索引 | 內容特徵 | 判斷 |
|---------|---------|------|
| 0 | 各列不同的固定格式代碼 | ORD_NO |
| 1 | 較短的不重複代碼 | MATM_NAME |
| 2 | 最長的中英數混合文字 | MATM_DESC |
| 3 | 英寸雙引號數字，大量重複 | WIDE |
| 4 | 單位詞，大量重複 | UNIT |
| 5 | 小數 1 位的數值 | QTY |
| 6 | 小數 2 位的數值 | PRICE |
| 7 | 約等於 欄5 x 欄6（500.0 x 22.00 = 11,000.00） | null（金額，不匯入） |
| 8 | 日期格式 | NEED_DATE |
| 9 | 只有「急單」與空值，無對應資料庫欄位 | null |
| 10 | 很短的代碼，大量重複 | NEED_CUST |

### 輸出

```json
{"mapping": ["ORD_NO", "MATM_NAME", "MATM_DESC", "WIDE", "UNIT", "QTY", "PRICE", null, "NEED_DATE", null, "NEED_CUST"]}
```

## 範例 2: 無表頭，欄位順序打亂，缺少部分欄位

### 輸入

欄位數 N = 8

```
R0: 0=1,460.0 | 1=碼 | 2=12.50 | 3=18,250.00 | 4=6AF2001 | 5=56"P28黑特利 | 6=2026/05/08 | 7=DS1
R1: 0=327.0 | 1=碼 | 2=8.40 | 3=2,747.00 | 4=6AF2002 | 5=44"1BC藍網布/(1BC) | 6=2026/05/15 | 7=LU1
R2: 0=75.0 | 1=公尺 | 2=41.20 | 3=3,090.00 | 4=6AF2003 | 5=60"2DE白尼龍布/(2DE) | 6=2026/05/22 | 7=DS1
```

### 判斷說明

| 欄位索引 | 內容特徵 | 判斷 |
|---------|---------|------|
| 0 | 小數 1 位的數值 | QTY |
| 1 | 單位詞 | UNIT |
| 2 | 小數 2 位的數值 | PRICE |
| 3 | 約等於 欄0 x 欄2（1,460.0 x 12.50 = 18,250.00；327.0 x 8.40 = 2,746.80，單據顯示 2,747.00，金額四捨五入到整數） | null（金額，不匯入） |
| 4 | 各列不同的固定格式代碼 | ORD_NO |
| 5 | 最長的中英數混合文字 | MATM_DESC |
| 6 | 日期格式 | NEED_DATE |
| 7 | 很短的代碼，大量重複 | NEED_CUST |

這份表格沒有料號欄與規格欄，因此 mapping 中不出現 MATM_NAME 與 WIDE。
不存在的欄位不需要補上，mapping 長度只與實際欄位數有關。

### 輸出

```json
{"mapping": ["QTY", "UNIT", "PRICE", null, "ORD_NO", "MATM_DESC", "NEED_DATE", "NEED_CUST"]}
```

## 範例 3: 有英文表頭

### 輸入

欄位數 N = 9

```
表頭: 0=PO Number | 1=Item No | 2=Description | 3=Width | 4=Qty | 5=Unit | 6=Unit Price | 7=Amount | 8=Delivery Date
R0: 0=PO-88120 | 1=A100 | 2=Mesh fabric 44" black | 3=44" | 4=2,000.0 | 5=YD | 6=3.250 | 7=6,500.00 | 8=2026-07-01
R1: 0=PO-88121 | 1=A101 | 2=Nylon 60" navy | 3=60" | 4=450.0 | 5=YD | 6=7.800 | 7=3,510.00 | 8=2026-07-08
```

### 判斷說明

有表頭時，以表頭比對 MAPPING.md 的標題別名，樣本值僅作為佐證。

| 欄位索引 | 表頭 | 判斷 |
|---------|------|------|
| 0 | PO Number | ORD_NO |
| 1 | Item No | MATM_NAME |
| 2 | Description | MATM_DESC |
| 3 | Width | WIDE |
| 4 | Qty | QTY |
| 5 | Unit | UNIT |
| 6 | Unit Price | PRICE |
| 7 | Amount | null（不匯入） |
| 8 | Delivery Date | NEED_DATE |

### 輸出

```json
{"mapping": ["ORD_NO", "MATM_NAME", "MATM_DESC", "WIDE", "QTY", "UNIT", "PRICE", null, "NEED_DATE"]}
```

## 輸出格式的錯誤示範

以下輸出皆不符合規範：

| 錯誤輸出 | 問題 |
|---------|------|
| `{"mapping": ["ORD_NO", "MATM_NAME", ..., "QTY"]}`（元素數少於 N） | 長度與欄位數不符，後續欄位會錯位 |
| `{"mapping": [0, 1, 2, 3, 4, 5, 6, 8, 9]}` | 輸出的是欄位索引，不是欄位名稱，且略過了不匯入的欄 |
| `{"mapping": ["ORD_NO", "QTY", "QTY", ...]}` | 同一欄位名稱出現兩次 |
| `{"mapping": ["訂購單號", "料號", ...]}` | 使用中文標題，而非詞彙內的英文欄位名稱 |
| `{"rows": [{"ORD_NO": "6AF3101", ...}]}` | 輸出了資料值，不屬於本 Skill 的範圍 |

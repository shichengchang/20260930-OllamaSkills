# 欄位判斷依據 - FENTAY B2B CLASSIFY

## 說明

本檔案是欄位語意判斷的唯一參考來源。
判斷以「表頭文字」為第一依據，「樣本值的內容特徵」為第二依據，與欄位的排列順序無關。
欄位索引的位置不具任何意義，同一份訂單可能把數量放在第一欄，也可能放在最後一欄。

---

## 標題別名（有表頭時使用）

任一別名符合即可判定。比對時忽略空白、全形半形與大小寫，標題內含別名文字亦視為符合，多個別名同時符合時取最長者。

| 欄位名稱 | 標題別名 |
|---------|---------|
| ORD_NO | 訂購單號、訂單號、訂單號碼、PO NO、PO Number |
| MATM_NAME | 料號、材料編號、品號、Item No、Part No |
| MATM_DESC | 材料名稱/顏色代碼、材料名稱、品名、顏色代碼、Description、Material Name |
| WIDE | 規格、幅寬、Spec、Width |
| QTY | 數量、訂購量、Qty、Quantity |
| UNIT | 單位、Unit |
| PRICE | 單價、Price、Unit Price |
| NEED_DATE | 交貨日期、需求日期、出貨日、Delivery Date、Ship Date |
| NEED_CUST | 需求子公司、子公司、需求公司、Sub Company |
| null（不匯入） | 金額、小計、合計、Amount、Total |

注意：「Price」與「Unit Price」屬於 PRICE，「Amount」與「Total」屬於不匯入欄位，兩者不可混淆。

## 內容特徵（無表頭或表頭無法比對時使用）

| 欄位名稱 | 樣本值的特徵 | 常見範例 |
|---------|-------------|---------|
| ORD_NO | 固定格式的英數字串，各列的值通常不同，且彼此格式相近 | 6AF1101、PO-88120 |
| MATM_NAME | 較短的英數代碼，可能整欄多列為空 | 3056G、A100 |
| MATM_DESC | 全表最長的文字欄，中文與英數混合，常含半形雙引號與括號 | 44"74F黃LJ-A8-P網布/(74F) |
| WIDE | 數字加英寸雙引號，或純數字，值的種類很少且大量重複 | 44"、60" |
| QTY | 數值，可含千分位，小數位常為 1 位 | 820.0、1,460.0 |
| UNIT | 簡短的單位詞，值的種類極少且大量重複 | 碼、YD、公尺、M、公斤、KG、個、PC |
| PRICE | 數值，小數位通常固定為 2 到 3 位 | 73.00、7.800 |
| NEED_DATE | 日期格式，含西元或民國年，各列的值落在相近區間 | 2026/03/27、2026-03-27、113/03/27、20260327 |
| NEED_CUST | 很短的英數代碼，值的種類很少且大量重複 | LU1、DS1 |
| null（金額） | 千分位數值，且約等於同列的數量乘以單價 | 59,860.00 |

## 易混淆欄位的消歧規則

### 數量、單價、金額

三者皆為數值欄位，無表頭時依下列順序判斷：

1. 找出「某欄 = 另外兩欄的乘積」的組合，該欄為金額（填 null）
2. 剩下的兩欄中，小數位為 1 位的是 QTY，小數位為 2 到 3 位的是 PRICE
3. 兩欄小數位相同時，排列順序在前者判為 QTY

驗算時以各樣本列逐列檢查，容許 0.01 以內的四捨五入誤差。

乘積關係是對稱的，只能找出金額欄，無法分辨 QTY 與 PRICE。第 2、3 點屬於弱證據，數值大小不可作為依據（單價高、數量少的訂單很常見，例如數量 2.0、單價 104.00）。

### ORD_NO、MATM_NAME、NEED_CUST

三者皆為短英數字串，區別在於重複程度與長度：

| 欄位 | 各列值的重複程度 | 長度 |
|------|----------------|------|
| ORD_NO | 幾乎不重複 | 中等 |
| MATM_NAME | 幾乎不重複，可能為空 | 中等或較短 |
| NEED_CUST | 大量重複 | 最短 |

ORD_NO 與 MATM_NAME 同為不重複的代碼時，格式與表頭文字優先；兩者仍無法區分，則較靠近表格左側者判為 ORD_NO，並讓另一欄維持 null。

### WIDE 與 MATM_DESC

MATM_DESC 的內容常以幅寬開頭（如 44"74F...），但整欄是長文字；WIDE 只有幅寬本身，內容極短。以長度區分，不以內容是否含有幅寬區分。

## 欄位值為空的處理

| 情況 | 判斷方式 |
|------|---------|
| 某欄在部分樣本列為空 | 以有值的樣本列判斷 |
| 某欄在所有樣本列皆為空，但有表頭 | 依表頭判斷 |
| 某欄在所有樣本列皆為空，且無表頭 | 填 null |

---

## 欄位索引對齊

mapping 的第 i 個元素永遠對應欄位索引 i，包含填 null 的欄位。
跳過不匯入的欄位會使後續所有欄位錯位，因此不匯入的欄位也必須以 null 佔位。

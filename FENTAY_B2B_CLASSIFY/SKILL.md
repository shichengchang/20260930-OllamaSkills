# 布料訂單欄位判斷 - FENTAY B2B CLASSIFY

## 用途
程式碼已將訂單表格切成「列」與「欄」，並取出每欄的樣本值。
本 Skill 的任務只有一件事：判斷每一欄代表 FENTAY_B2B 的哪個欄位。

資料值的擷取、單位轉換、日期轉換、數值格式、預設值填寫，全部由程式碼處理，不屬於本 Skill 的範圍。

## 與 fentay-b2b 的分工

| 項目 | fentay-b2b | fentay-b2b-classify |
|------|-----------|---------------------|
| AI 的輸出 | 完整 JSON 資料（每筆每欄的值） | 僅有 mapping 陣列 |
| AI 是否接觸資料值 | 是，需逐字輸出 | 否，只讀取樣本判斷語意 |
| 單位、日期、數值轉換 | 由 AI 套用 MAPPING.md | 由程式碼套用 |
| 輸出長度 | 隨資料筆數增加 | 固定，與欄位數相同 |

## 輸入

程式碼會提供以下內容：

- 表格欄位數 N
- 若干列樣本資料，每列格式為「欄位索引=值」，索引從 0 開始
- 表頭文字（選用，有些來源沒有表頭）

## 輸出

輸出僅含一個 JSON 物件，結構如下：

```json
{"mapping": ["ORD_NO", "MATM_NAME", "MATM_DESC", "WIDE", "QTY", "UNIT", "PRICE", null, "NEED_DATE", "NEED_CUST"]}
```

輸出格式的限制：

- mapping 的長度等於欄位數 N，第 i 個元素對應欄位索引 i
- 每個元素為欄位名稱字串或 null
- 同一個欄位名稱在 mapping 中最多出現一次
- 輸出內不含資料值、說明文字、markdown 程式碼圍籬

## 判斷流程

1. 若有表頭文字，優先以表頭比對 MAPPING.md 的標題別名
2. 表頭缺漏、為空或無法比對時，依樣本值的內容特徵判斷
3. 數量、單價、金額三個數值欄位難以區分時，以「數量 x 單價 約等於 金額」的關係消歧（金額四捨五入到整數，誤差在 0.5 以內）
4. 仍無法判斷的欄位填 null

## 欄位名稱詞彙

mapping 的元素只能取自下列字串，或 null：

`ORD_NO`、`MATM_NAME`、`MATM_DESC`、`WIDE`、`QTY`、`UNIT`、`PRICE`、`NEED_DATE`、`NEED_CUST`

BRAND_NO、CUST_NO、CONTACT_NO 不出現在訂單表格中，不屬於詞彙範圍。

## 填 null 的情況

| 情況 | 說明 |
|------|------|
| 金額、小計、合計欄 | 依規則不匯入資料庫 |
| 備註、序號、頁碼等無對應欄位的內容 | 沒有可對應的資料庫欄位 |
| 樣本值全為空且無表頭 | 缺少判斷依據，不猜測 |

完整的欄位特徵、標題別名、消歧規則見 [MAPPING.md](MAPPING.md)，範例見 [EXAMPLES.md](EXAMPLES.md)。

**EXAMPLES.md 的欄位順序與欄位數刻意與實際訂單不同，僅供格式參考。實際判斷以輸入的樣本內容為準。**
